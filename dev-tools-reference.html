🎯 fd
Simple, fast alternative to find
▼
Find Files
fd pattern

fd -t f "\.js$"
Advanced Usage
fd -H "hidden_files"
fd -E node_modules "package.json"
fd -x chmod 644
Type Filters
-t f - Files only
-t d - Directories only
-t l - Symlinks
-t x - Executables
